# Ballerina FreeMarker Examples

This directory contains examples that demonstrate how to use the `ballerinax/freemarker` library.

## Examples

- [**Order confirmation email**](order-confirmation-email) — Generates a formatted order confirmation email from a FreeMarker template file. Demonstrates variable interpolation, `<#list>` for iterating over line items, and `<#if>` for conditional content (e.g., showing a reward points message for premium members).

## Running an example

Ensure you have [Ballerina](https://ballerina.io/downloads/) installed, then navigate into the example directory and run:

```bash
bal run
```
