3. ROOT CAUSE ANALYSIS
───────────────────────────────────────────────────────────────────────
Category        : Infrastructure - Database
Root Cause      :
  Primary RDS instance ran out of connection pool capacity after a connection leak was introduced in deploy v4.12.1, causing all new DB connections to be refused and transactions to fail with a timeout.

Contributing Factors:
  - Connection leak in v4.12.1 not caught by pre-prod load tests
  - Connection pool exhaustion alert threshold set too high (95% instead of 75%)
  - Canary deployment skipped due to release timeline pressure

Trigger Event   : Deployment of payment-service v4.12.1 at 10:58 UTC
First Alert     : Datadog synthetic monitor at 2026-04-15 11:02:00 UTC
Detection Method: Datadog synthetic monitor + PagerDuty page
