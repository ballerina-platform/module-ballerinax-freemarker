IMPROVEMENTS
────────────────────────────────────────────────────────────────────────────
  * Update Netty to 4.1.109 for security patches  (HTTP-7988)
  * Improve connection close log message to include remote address  (HTTP-7971)
  * Reduce log level of routine keep-alive probe messages from WARN to DEBUG  (HTTP-7960)

BUG FIXES
────────────────────────────────────────────────────────────────────────────
  [HIGH]  Fix NPE when response body is null in HTTP/2 trailers  (HTTP-7999)
  [HIGH]  Fix connection pool starvation under burst traffic with slow upstreams  (HTTP-7991)
  [MEDIUM]  Fix incorrect status code mapping for 308 Permanent Redirect  (HTTP-7975)
  [LOW]  Fix typo in log message for SSL certificate expiry warning  (HTTP-7962)
  [LOW]  Fix inconsistent line endings in HTTP header serialisation on Windows  (HTTP-7951)
